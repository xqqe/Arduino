**An evolving collection of Arduino sketches, hardware prototypes, interactive controllers, and PCB designs.**

This repository documents hands-on experiments in embedded electronics: microcontroller programming, user interfaces, rotary encoders, Bluetooth HID controls, OLED displays, RGB indicators, timing logic, and custom printed circuit boards.

It contains both **standalone hardware tests** and iterations toward more integrated devices. The code is preserved as a development archive, so not every sketch is a finished or portable project.

## Featured projects

### Multiplayer game timer — `MTG/`

A series of embedded timer prototypes developed around turn-based tabletop gameplay, particularly **Magic: The Gathering**.

The implementations explore:

- Independent player time counters and turn switching
- Pause/resume logic with button debounce
- Player information including life totals, infection counters, and related game state
- RGB color indication for player selection
- Joystick/rotary input and OLED user interfaces
- Refactoring from monolithic sketches into separate function and variable headers

Start with [`MTG/mtg_timer_1/`](MTG/mtg_timer_1/) for a timer implementation, or browse the other iterations to see how the program structure and interface evolved.

### Bluetooth macro controller

The [`TESTS/ble_dial_working/`](TESTS/ble_dial_working/) prototype combines a rotary encoder and 3 × 3 keypad with Bluetooth keyboard and mouse output.

The sketch includes:

- Quadrature rotary-encoder reading
- Mouse wheel events generated by dial rotation
- Configurable keyboard shortcuts for keypad buttons
- Encoder push-button actions
- BLE HID integration using `BLE52_Mouse_and_Keyboard`

This is a hardware-specific example; its pin assignments and Bluetooth libraries must match the target board. Related sketches in `TESTS/` cover individual BLE and rotary input experiments.

### Multi-display OLED experiment

[`HelloWorld_SPI_workingexample/`](HelloWorld_SPI_workingexample/) demonstrates driving **five SH1106 128 × 64 OLED screens** over hardware SPI, with separate chip-select, data/command, and reset pin assignments for each display.

The sketch uses the `U8g2` graphics library and writes independently to each screen. It serves as a concrete reference for coordinating multiple small displays with a single microcontroller.

Additional OLED examples cover I²C connections, graphics tests, button interaction, and screen layouts.

### PCB and hardware design archive

[`PCB/online_projects_backup/`](PCB/online_projects_backup/) preserves a substantial set of **EasyEDA schematic and PCB JSON backups**. Projects include:

- Macro pads and keyboard switch matrices
- MX and Choc switch variants
- LED-integrated keyboard layouts
- Rotary-dial interfaces
- Controller and microcontroller breakout boards
- Small experimental display and input circuits
- Timer and counter board designs

The archive includes multiple design revisions, routed and unrouted boards, and copies of ongoing experiments. Files are development snapshots, **not verified fabrication-ready releases**.

## Getting started

### Arduino sketches

1. Install the [Arduino IDE](https://www.arduino.cc/en/software) or configure an appropriate Arduino development environment.
2. Clone the repository:

   ```bash
   git clone https://github.com/xqqe/arduino.git
   ```

3. Open the desired `.ino` sketch in its project folder.
4. Select the correct **board** and **port** in the IDE.
5. Install any dependencies imported by that sketch.
6. Check pin definitions and hardware connections before compiling or uploading.

**Dependencies vary by project.** The code references libraries such as `U8g2`, `RGBLed`, `Keypad`, `Adafruit_NeoPixel`, and BLE/HID packages. The repository also contains copies of several libraries under `TESTS/libraries/`; review their own documentation and licenses rather than assuming they are installed automatically.

Some test code targets boards with different hardware features (for example, BLE-capable controllers or an Arduino Mega pin layout). Do not assume the same sketch and wiring will work unchanged on an Arduino Uno, Nano, or another board.

### Recovering EasyEDA projects

To inspect a saved PCB project:

1. Open [`PCB/online_projects_backup/`](PCB/online_projects_backup/).
2. Find the named design folder; schematic files are generally under `sch/` and board files under `pcb/`.
3. Open the EasyEDA editor and use its **Open / EasyEDA** import functionality.
4. Import the relevant JSON schematic and board files.
5. Save the recovered design as a new project.

The archive also includes an original [recovery note](PCB/online_projects_backup/how%20to%20recover%20online%20project%20backup.txt). EasyEDA menu labels may vary between versions.

## Engineering topics explored

The sketches and design files illustrate several recurring embedded-development concepts:

**Firmware and control logic:** `millis()`-based timers, event polling, button debouncing, state tracking, and menu/display updates.

**Hardware interfaces:** GPIO, analog joystick readings, quadrature encoders, RGB LEDs, buzzers, and matrix keypads.

**Display integration:** SH1106 OLEDs using I²C and SPI, custom text/graphics rendering, and control of multiple displays.

**Human-interface devices:** USB/Bluetooth keyboard and mouse behavior, button-to-shortcut mappings, and rotary controls.

**Electronics design:** schematics, PCB routing, custom input layouts, breakout boards, and revision-based prototyping.

## Notes on reuse

This repository primarily serves as a historical collection of personal hardware work rather than a maintained Arduino library. Before adapting a project:

- Verify the board model, pin numbers, operating voltages, and peripheral wiring.
- Check that the required libraries support the intended microcontroller.
- Expect differences among sketch versions; some are partial or exploratory.
- Validate PCB footprints, pinouts, electrical rules, and manufacturing outputs before ordering boards.
- Review licenses in bundled third-party libraries; their inclusion does not imply original authorship.
